# Traducciones pendientes

Nombres que no están en `lib/rules/i18n/es.json` porque no se pudo confirmar el nombre oficial de la edición española de 2024. Mientras falten, la aplicación muestra el nombre en inglés. Para añadir uno, copia la clave y el nombre confirmado a `es.json` y vuelve a ejecutar `npm run import:5etools`.

Fuentes usadas para lo que sí está en `es.json`: el SRD 5.2.1 oficial en español (https://www.dndbeyond.com/srd) y, para lo que no está en el SRD, la lista de subclases y trasfondos del análisis de Espada y Escudo (https://www.espadayescudo.com/blog/analisis-manual-del-jugador-2024/), que coincide con el SRD en todos los nombres que comparten.
